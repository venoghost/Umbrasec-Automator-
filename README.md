# Umbrasec-Automator-Kali Tools Automation Dashboard
Built a web-based cybersecurity automation dashboard designed to simplify and streamline the use of Kali Linux security tools. The project focuses on bringing multiple security workflows into a centralized interface rather than requiring users to manually execute and manage individual tools from the terminal.

The project gave me hands-on experience with full-stack development, security-tool integration, automation workflows, application architecture, and AI-assisted development. I worked with a modern web stack including Next.js/TypeScript, reusable components, API/application logic, Prisma, and testing.
